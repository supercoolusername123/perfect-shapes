About Nail the Shape

Nail the Shape is a small browser game built around a simple challenge: draw a familiar shape as accurately as you can in one smooth motion. The available shapes are circle, square, triangle, diamond, and hexagon. Each round is quick, but the score gives enough feedback to make improvement feel possible.

The game is designed to be easy to understand without instructions, while still rewarding careful movement. A strong score usually comes from drawing around the center guide, keeping the outline close to the target shape, closing the path cleanly, and avoiding long pauses or extra loops.

Nail the Shape also includes local personal bests and a global leaderboard for each shape. The leaderboard is meant to keep competition lightweight and fair: each player name can appear once per shape, and a better score replaces an older score using the same name.

This site is maintained as an independent web game. If you have feedback, find a bug, or want to report a leaderboard issue, please use the contact page.
